# Smart Resume Builder

A web-based application that helps users create and organize their resumes using a simple and user-friendly interface.

## Features

- Enter personal and contact information.
- Add educational qualifications and skills.
- Include experience and project details.
- Add professional profile links such as GitHub, LinkedIn, LeetCode, and CodeChef.
- Generate a resume from the entered information.
- Print or save the resume as a PDF.

## Technologies Used

- HTML
- CSS
- JavaScript
- Java

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `src/main/webapp/index.html` in a browser to try the frontend.
4. If the project requires Java backend functionality, configure the required Java web server and dependencies before running it.
